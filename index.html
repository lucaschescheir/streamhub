TMDB key (for the movie & TV catalog)

Streaming services don't publish their catalogs, so this app uses The Movie Database (TMDB), which tracks what's on each service (data from JustWatch). A key is free: create an account at themoviedb.org, then go to Settings → API and copy either the API Key or the API Read Access Token. Sports schedules work without a key.
To browse movies and shows, add a free TMDB key in My Services.
